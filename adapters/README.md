# Adaptadores

Cada portal confirmado en el catálogo Oracle recibe una aplicación versionada e independiente, con funciones por documento, dependencias fijadas y contrato documentado. Los releases TEST actuales incluyen candidatos para Servicios Educación (`documento_9`) y SENESCYT (`documento_10`), creados desde el prototipo histórico. Sus asignaciones están preparadas en Oracle TEST; aún no tienen consulta real atendida, ejecución integrada ni ACK. El código público excluye sujetos, evidencias, credenciales y endpoints ORDS internos.
