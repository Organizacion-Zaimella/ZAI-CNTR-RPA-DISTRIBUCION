# Adaptadores

Solo un portal confirmado en el catálogo Oracle y aprobado para publicación recibirá `adapters/<portal_slug>/` con `src/`, `tests/`, `dependencies.lock`, `manifest.template.json` y README propios. El código público excluirá sujetos, evidencias, secretos y endpoints ORDS internos. Las funciones por documento se migrarán en tareas posteriores desde código y evidencia existentes; este bootstrap no declara adaptadores disponibles.
