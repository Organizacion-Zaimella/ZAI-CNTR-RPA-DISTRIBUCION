# Seguridad

No publique vulnerabilidades, credenciales, datos personales ni evidencias mediante Issues o discusiones públicas.

El canal corporativo de reporte privado y su responsable están **pendientes de verificación y aprobación**. Hasta entonces no se declara un correo ni un proceso externo como canal oficial. Las futuras instrucciones de reporte privado se actualizarán aquí una vez confirmadas; una publicación de software también requiere ese control.

Las claves privadas de firma, secretos de CI y credenciales de Oracle/ORDS/GitHub nunca pertenecen a este repositorio. Las claves públicas de verificación solo se publicarán tras aprobar el esquema de firma y su custodia.
